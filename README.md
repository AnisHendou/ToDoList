#To Do List Project.
A simple yet efficient command-line To-Do List Manager built with Python, allowing users to add, delete, and track tasks with timestamps.

📌 Features
✔ Add a Task – Insert a new task with a description and optional start time.
✔ Delete a Task – Remove a task by its index.
✔ Mark as Done – Update task status to "Completed."
✔ View All Tasks – Display tasks with their status and timestamps.
✔ Exit the Program – Safely close the application.

🛠️ Installation & Setup

Clone the repository:

git clone https://github.com/AnisHendou/ToDoList.git
cd ToDoList/

Run the Application

python todo.py

📋 Usage
Add a Task:
Enter task description and optional start time.

Delete a Task:
Select a task by its number to remove it.

Mark as Done:
Choose a task to mark it as completed.

View Tasks:
See all pending and completed tasks with timestamps.

Exit:
Close the program safely.
